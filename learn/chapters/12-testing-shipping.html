Testing an agent without a model

A real LLM is slow, costs money and answers differently each time. Script it instead.

Pseudocode · an end-to-end agent test
const llm = scriptedModel([
  callTools({
    name: 'get_stock_level',
    args: { productId: 101 }
  }),
  say('Ceramic Pour-Over Set: 3 left.')
]);

// agent → client → store server → mock store
const result = await agent.run(
  'How many pour-over sets are left?',
  { llm }
);

expect(result.toolCalls[0].outcome)
  .toBe('ok');
Why it works
  • Each step is a function of the conversation so far, like a real model's turn.
  • callTools() makes the "model" request tools; say() makes it answer.
  • Everything below the model is real: agent loop, approval policy, MCP client, store server, mock store.
  • If the script runs out of steps, throw, so a loop that never stops fails loudly.
  • Cover approval, declined writes, tool errors fed back to the model, hallucinated tools and the step budget.

🔍 Debug

MCP Inspector: a client for humans

The official debugging tool. Connect to a running server and click through tools, resources and prompts.

Usage follows the official docs at modelcontextprotocol.io. The Inspector needs Node 22.19 or newer, so check node -v first.

Logs the operator can trust

Write one JSON line per event. Pick a level to see what survives.

A logger worth having
  • JSON lines on stderr: time, level, logger, message, plus context.
  • A request ID on every line, from an x-request-id header or a fresh UUID, echoed back in the response.
  • Redaction: keys like token, authorization, email or phone become [redacted].
  • A level setting (e.g. LOG_LEVEL): debug · info · warn · error. Tests run silent.
  • Logs stay with the operator. Revision 2026-07-28 deprecates the MCP logging capability, so don't plan on sending logs to clients.

1 · WHAT CI RUNS

2 · ONE LAYER AT A TIME
npx vitest run tests/integration
npx vitest run tests/e2e
3 · THE DOCKER SMOKE TEST
docker compose up -d --build --wait
docker compose run --rm smoke-client
4 · INSPECT BY HAND
npx @modelcontextprotocol/inspector \
  --server-url http://localhost:3000/mcp \
  --transport http --protocol-era auto \
  --header "Authorization: Bearer $TOKEN"

Health check while the server runs: curl http://localhost:3000/healthz should return {"status":"ok"}. Use a dev-only token, never a production one. Docs: MCP Inspector.

🎯 Key takeaways

  • Test each bug at the cheapest layer that can catch it: unit → integration → end to end.
  • Script the model so agent tests are fast and repeatable; keep everything below it real.
  • Ship boring: frozen lockfile, typecheck, tests, a health check, and logs with request IDs and no secrets.
