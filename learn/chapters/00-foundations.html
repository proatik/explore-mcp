    🧱 Primitives

    Three things a server offers

    The difference is who decides to use them.

    🛠️

    Tools

    Model-controlled
    • Functions the LLM can call to act or fetch
    • Typed input and output schemas
    • Need user consent before running
    In the example store
    search_productsupdate_stock
    📚

    Resources

    Application-controlled
    • Data the app attaches as context
    • Addressed by a URI
    • Templates fill in IDs, e.g. a product
    In the example store
    shop://store/infoshop://products/{productId}
    💬

    Prompts

    User-controlled
    • Templates the user picks, like a slash command
    • Take arguments
    • Can embed live data
    In the example store
    draft_customer_replysummarize_sales

    What a client can offer back

    Servers ask the client for input. In the 2026-07-28 revision, two of these are deprecated.

    🙋 Elicitation Current

    • Server asks the user for missing info
    • e.g. "Which warehouse?"

    🧠 Sampling Deprecated

    • Server asked the client's LLM to generate text
    • Now: call an LLM provider directly

    📁 Roots Deprecated

    • Client told the server which folders matter
    • Now: pass paths via tool inputs, URIs or config

    A simple store server needs none of these. Source: MCP spec 2026-07-28, deprecated features registry.

    MCP vs REST vs function calling

    MCP doesn't replace REST. The store server still calls the store's own API over REST.

    REST APILLM function callingMCP
    Built forApps calling servicesOne LLM calling an app's functionsAny AI host using any server
    DiscoveryDocs or optional OpenAPIYou hand-write each schematools/list, resources/list, prompts/list
    PortablePer APIPer LLM vendor formatOne server, many hosts
    Context, not just actions✗✗Resources and prompts
    Consent modelYour app's jobYour app's jobSpec says hosts must get user consent

    A host often uses both: MCP to reach servers, then hands their tools to its LLM as function calls (Chapter 08).

    🎯 Key takeaways

    • MCP turns N × M custom integrations into N + M.
    • Host runs the AI and owns consent. Each client talks to exactly one server.
    • Tools are model-controlled, resources app-controlled, prompts user-controlled.
